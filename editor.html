Widgets

Widgets sind zusätzliche Blöcke. Einige brauchen später einen Account/API, deshalb wird hier erklärt, was sie benötigen.

Discord StatusBenötigt eine Discord-Verbindung, damit ein echter Status angezeigt werden kann.
SpotifyBenötigt eine Spotify-Verbindung für den aktuell laufenden Song.
WeatherBenötigt eine Wetter-API und einen Standort.
ProjectsKann später eigene Projekte auf deinem Profil anzeigen.
